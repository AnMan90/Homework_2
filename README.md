# Homework_2

## Описание:

Homework_2 - E-commerce — электронная торговля, или электронная коммерция.
На данном этапе работы мы не будем реализовывать систему платежей, однако подготовим всё для того,
чтобы у нас появилось ядро для интернет-магазина. В дальнейшем для этого ядра возможно
будет реализовать любой интерфейс — от сайта до телеграм-бота.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/AnMan90/Homework_2.git
```
2. Установите зависимости:
```
poetry install
```
## Тестирование

Код протестирован с помощью pytest. Отчет о покрытии кода тестами находится в папке htmlcov, в корне проекта.

## Модуль product_class.py

В модуле представлен класс Product, который состоит из наименования продукта,
его описания, цены и количества. Реализовано сложение общей цены всех продуктов. 

## Модуль product_subclass.py

Модуль содержит дочерние классы от класса Product, а именно класс Smartphone и класс LawnGrass.

## Модуль category_class.py

В модуле представлен класс Category, который состоит из категории продукта, его описания, 
а так же списка продуктов входящих в данную категорию. Помимо этого реализован подсчет количества категорий
и количества товаров, а так же возможность добавления товаров.
